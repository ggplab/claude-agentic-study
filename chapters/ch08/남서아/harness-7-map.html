ch08 하네스 엔지니어링 · 남서아
요소무엇인가헤르메스 현재상태적용안
① 자기검증 루프 AI가 작업 결과를 스스로 검사하고, 틀렸으면 다시 고치게 하는 장치 점검 스크립트(smoke_test.py)는 있으나 사람이 돌려야 함. 자기수정 경로엔 미연결 공백 1순위 — 자기수정 시 git 저장 → 수정 → 점검 통과 → 실패 시 되돌리기
② 컨텍스트 맵 프로젝트 전체 구조 지도를 AI에 줘서, 일부만 보고 고치다 다른 곳을 깨뜨리지 않게 지식(위키)엔 탐색 순서가 있으나 자기 코드엔 지도 없음 부분 스크립트 역할·의존관계 문서 1개 (Repomix로 초안)
③ 세션 지속성 대화가 끊겨도 진행 상황·결정이 남아 다음 세션이 이어받게 위키·log.md — 단 구직 업무용이지 코딩 작업용 아님 업무용 유지
④ 실패 체크리스트 AI가 반복하는 실수를 목록으로 만들어 매번 참조하게 SOUL 절대금지·위임 시 ponytail 원칙 — 대화용이고 코드 수정용은 없음 부분 실제 사고를 위키에 쌓고 자기수정 프롬프트가 필독
⑤ 언어 독립성 하네스가 특정 프로그래밍 언어에 묶이지 않게 파이썬 단일 킷이라 해당 없음 N/A 도입 안 함
⑥ 가비지 컬렉션 쓸모없어진 코드·파일·컨텍스트를 정기적으로 청소 구직 노트 청소 스크립트는 있으나 코드 청소는 아님 업무용 필요해지면 Vulture(파이썬 죽은 코드 탐지)
⑦ 스캐폴딩 우선 빈 화면에서 짓게 하지 않고, 틀을 먼저 깔고 채우게 킷 자체가 템플릿 묶음 + plugins/ 폴더 구조 있음 부분 2순위 — 새 기능은 플러그인으로만, 코어는 자기수정 금지
헤르메스는 hermes-agent-kit 폴더를 직접 열어 확인 (2026-07-26) · 상세는 README 참조
