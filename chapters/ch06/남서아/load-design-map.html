① 무엇을 / 언제 — 지침 파일 4종의 로드 시점

파일축로드 시점특징
CLAUDE.md 항상무엇을 기억할 것인가세션 시작 시 전문트리 위로 걸어 올라가며 전부 concat (덮어쓰기 아님) · 200줄 이하 권장
@import 항상정리(모듈화)세션 시작 시 전개최대 4단계 재귀 · 컨텍스트 절약은 안 됨 — 어차피 다 로드
rules + paths: 조건부언제 적용할 것인가매칭 파일을 read할 때glob(`src/**/*.ts`)으로 범위 지정 · paths 없으면 "항상"과 동일
스킬 요청 시작업 절차모델이 맥락 맞다고 판단할 때평소엔 description만 상주 (점진적 공개)

② 수명 타임라인 — 언로드 규칙은 없다 확인됨

세션 시작CLAUDE.md 전문 + paths 없는 rules 로드
작업 중매칭 read → paths rule 추가 로드. 한번 들어오면 계속 상주
/compact루트 CLAUDE.md만 재주입. 하위 CLAUDE.md·paths rule은 소실 (다음 매칭 read 때 재로드)
/clear · 세션 끝전부 소멸. 이것이 유일한 "언로드"
선택적 로드는 있는데 선택적 언로드는 없다 → 안 쓰는 지침이 세션 내내 컨텍스트를 차지하지 않게 하려면, 애초에 로드 조건(paths·스킬 트리거)을 좁게 설계하는 수밖에 없다.
