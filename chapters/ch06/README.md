### 문종운 — 세션은 사라진다: 무엇이 `/compact`를 살아남는가
- **내용 리마인드**: 메모리를 "4계층 표"가 아니라 **실행 시점의 생존 관점**으로 본다. `/compact`는 대화를 요약해 컨텍스트만 비우는데, 이때 **디스크에 있는 것은 재주입되고(루트 CLAUDE.md, auto memory) 대화에만 있던 것은 사라진다**. 특히 **하위 디렉터리 `CLAUDE.md`와 `paths:` 붙은 rules는 소실**된다 — 긴 세션 후반부에 규칙이 조용히 안 지켜지는 이유. 또한 우선순위는 override가 아니라 **concat**(전부 이어붙음)이라, 모순된 규칙을 여러 계층에 두면 클로드가 임의로 고른다.
- **나에게 어떤 의미였나**: 실측해보니 내 `~/.claude/CLAUDE.md`(60줄)·`./CLAUDE.md`(38줄)는 200줄 규격을 통과했지만 **`@import`를 하나도 안 쓰고 있었다**(마크다운 링크를 import로 착각). auto memory는 프로젝트 스코프에만 있고(MEMORY.md 6줄/794B, 한도의 3%), 그중 `skill-create-bundle-wip.md`는 **이미 커밋됐는데 이름이 여전히 WIP** — 정리 대상 1호. 세션은 `~/.claude/projects/<slug>/*.jsonl`에 10개(전체 50MB), `cleanupPeriodDays` 미설정으로 **기본 30일** — 주 1회 스터디엔 아슬아슬해서 늘릴지 고민 중. 정리본: [문종운/README.md](문종운/README.md)
