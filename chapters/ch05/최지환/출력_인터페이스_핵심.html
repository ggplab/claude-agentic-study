5-1

출력 스타일 커스터마이징

output style

출력 스타일은 형식만 바꾸는 게 아니라 시스템 프롬프트 자체를 교체한다. 기본이 아닌 스타일을 고르면 엔지니어링 지침이 제거되고 사용자 지침으로 대체된다 — 그래서 코딩을 넘어 문서·교육·분석 도구로 확장할 수 있다.

Default 기본

소프트웨어 엔지니어링에 최적화된 기본 프롬프트. 간결한 응답.

언제 · 대부분의 일반 개발 작업

Proactive 실행

멈춰 묻지 않고 합리적으로 가정해 바로 실행. 계획보다 행동 우선.

언제 · 자율 실행을 원할 때

Explanatory 설명

작업을 완료하며 구현 선택의 이유를 교육적으로 함께 설명.

언제 · 코드 리뷰, 새 기술 스택 학습

Learning 학습

인사이트만 주고 TODO(human) 마커로 구현은 개발자에게 넘김.

언제 · 직접 손으로 익히는 실습

전환은 /config → Output style(예전 /output-style 명령은 v2.1.91에서 제거). 세션 시작 시 한 번 로드되므로 변경 후 /clear나 새 세션에서 적용된다. 커스텀 스타일은 ~/.claude/output-styles/(사용자) 또는 .claude/output-styles/(프로젝트)에 마크다운으로 저장하고, 팀 기본값은 .claude/settings.json의 outputStyle 키로 고정.

↔

비슷하지만 다른 네 기능

응답 방식 vs 작업 실행
기능동작영향 범위
Output Style시스템 프롬프트 완전 대체메인 에이전트 응답 방식
CLAUDE.md시스템 프롬프트 추가기본 지침 유지 + 컨텍스트
서브에이전트독립 컨텍스트 작업 위임메인과 분리된 실행
슬래시 명령어저장된 프롬프트 실행정해진 워크플로

핵심 구분 — Output Style은 "어떻게 응답하는가", 슬래시 명령은 "무슨 작업을 하는가". 둘을 조합하면 특정 스타일로 특정 작업을 수행하는 일관된 워크플로가 된다.

⚠

환각 방지 지침

anti-hallucination

출력 스타일에 검증 규칙을 심으면 요청마다 반복하지 않아도 시스템 수준에서 일관되게 환각을 줄인다. 정확성이 중요한 기술 문서·API·코드 리뷰에서 특히 차이가 난다.

▹ 세 가지 규칙
  • 출처 없는 URL 금지 — WebFetch/WebSearch가 실제 반환한 URL만 인용, 패턴으로 추측 생성 금지
  • 확인 없는 버전·API 주장 금지 — 파일 시스템·문서 검색으로 검증한 것만
  • 불확실성 표현 허용 — "검증이 필요합니다" 같은 표현을 명시적으로 열어 두기

응답에 신뢰도 표시를 붙인다 — [검증됨] · [가능성 높음] · [불확실], 그리고 출처: (파일:줄번호) / (WebFetch URL) / (Context7 버전).

5-2

상태 표시줄

statusline

스크립트가 클로드 코드로부터 JSON을 stdin으로 받아 가공하고 한 줄을 stdout으로 내보낸다. 대화가 갱신될 때마다 최대 300ms 간격으로 다시 그려지므로 — 스크립트는 빠를수록 좋다.

클로드 코드JSON 데이터
→
stdinmodel · cost · workspace
→
파싱 + 포매팅bash / python / node
→
stdout터미널 하단 한 줄

설정

/statusline으로 안내 생성, 또는 settings.json에 statusLine 키(type: command)로 스크립트 경로 지정.

색상 · ANSI

ANSI 이스케이프로 세그먼트 구분 — 추가 라인은 녹색, 삭제는 빨강. echo -e 필수.

성능 · 캐싱

깃 브랜치처럼 비싼 조회는 /tmp에 5초 TTL로 캐싱. 자주 실행되므로 최적화가 중요.

안 보일 때 · 실행 권한(chmod +x) → stdout 출력 확인(stderr X) → jq 설치 여부(brew install jq). 수동 테스트는 목 JSON을 파이프로 흘려보내 확인.

5-3

대화형 모드

interactive mode

빠른 명령 접두사 — 첫 글자 하나로 입력의 처리 방식이 바뀐다.

#
메모리 단축키CLAUDE.md에 바로 기록되어 이후 세션에서도 참조
/
슬래시 명령/help·/clear·/config 및 커스텀 명령 호출
!
Bash 모드승인 없이 셸 명령 직접 실행, 출력이 컨텍스트에 추가
@
파일 경로 멘션경로 자동 완성으로 파일을 컨텍스트에 포함

자주 쓰는 단축키

Ctrl + C
현재 입력·생성 취소 (표준 중단)
Ctrl + R
역방향 명령 기록 검색 — 디렉터리별 저장
Ctrl + O
상세 출력 토글 — 도구 사용·실행 자세히
Ctrl + B
현재 Bash 명령을 백그라운드로 (Tmux는 두 번)
Esc Esc
코드·대화를 이전 지점으로 되감기 (체크포인트)
Tab
확장 사고 토글 — 복잡한 문제를 더 깊이
Shift + Tab
권한 모드 전환 — 자동 수락 · 계획 · 일반
Shift + Enter
다중 줄 입력 (/terminal-setup 후)

백그라운드 Bash는 빌드·테스트·개발 서버 같은 장기 실행을 비동기로 돌리고, 그동안 다른 파일을 분석하게 한다. 출력은 BashOutput으로 나중에 회수. 이미지는 Ctrl+V로 붙여 넣어 에러 스크린샷·UI 목업을 그대로 전달.
