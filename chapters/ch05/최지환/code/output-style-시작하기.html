Chapter 05 · 완전 초보자용

출력 스타일, 처음부터 따라 하기

클로드 코드를 오늘 처음 켠 사람도 위에서 아래로 순서대로만 따라 하면 나만의 출력 스타일을 만들어 적용할 수 있게 만든 문서다. 명령어를 그대로 복사해서 붙여 넣으면 된다.

▹ 한 줄 정의

출력 스타일 = 클로드의 "말투와 집중 영역"을 통째로 바꾸는 스위치. 글자 색이나 형식만 바꾸는 게 아니라 클로드가 따르는 시스템 프롬프트 자체를 교체한다. 그래서 기본이 아닌 스타일을 고르면 "코딩 도우미" 지침이 빠지고, 내가 적어 준 지침이 그 자리를 대신한다.

준비물은 딱 하나 — 터미널에서 claude로 클로드 코드가 실행돼 있으면 된다. 아래 /로 시작하는 건 클로드 코드 안에서 입력하고, $로 시작하는 건 일반 터미널에 입력한다.

먼저 손에 익히기

built-in styles
▹ 명령어가 바뀌었다
  • 예전 /output-style 명령은 v2.1.73에서 폐기되고 v2.1.91에서 제거됐다. 이제 스타일 전환은 전부 /config 메뉴의 Output style로 한다.
1

지금 뭐가 켜져 있는지 본다

클로드 코드 입력창에 /config를 치고 Output style 항목을 고른다. 설치된 스타일 목록이 뜨고 지금 선택된 것에 표시가 붙는다.

클로드 코드 안에서
/config   # → 메뉴에서 "Output style" 선택

기본 4종(Default · Proactive · Explanatory · Learning)이 목록에 보이면 정상.

2

기본 제공 스타일을 하나 바꿔 본다

/config → Output style에서 목록 중 하나를 고른다. 선택은 .claude/settings.local.json에 자동 저장된다.

Default

엔지니어링에 최적화된 간결한 기본.

Proactive NEW

멈춰 묻지 않고 합리적으로 가정해 바로 실행.

Explanatory

작업하며 "왜 이렇게 했는지"까지 설명.

Learning

인사이트 + TODO(human)로 일부는 내가 직접.

바꾼 스타일은 /clear 하거나 새 세션부터 적용된다 — 출력 스타일은 세션 시작 때 한 번만 읽기 때문.

나만의 스타일 만들기

custom style
3

스타일 파일 하나를 만든다

출력 스타일은 그냥 마크다운 파일 한 개다. 맨 위 --- 사이에 메타데이터를 적고, 그 아래에 클로드에게 줄 지침을 자유롭게 쓴다. 아래 내용을 my-style.md로 저장한다.

파일 내용 · my-style.md
---
name: 한국어 설명형
description: 한국어로 답하고 이유까지 설명하는 스타일
keep-coding-instructions: true
---

# 커스텀 지침

## 응답 언어
항상 한국어로 응답한다.

## 집중 영역
- 왜 그렇게 구현했는지 이유를 함께 설명한다.
- 코드에는 한국어 주석을 넉넉히 단다.
  • name — /config 목록에 뜨는 이름. 없으면 파일 이름이 그대로 이름이 된다.
  • description — 목록 옆 한 줄 설명.
  • keep-coding-instructions — 기본값 false. 커스텀 스타일은 기본적으로 클로드의 코딩 지침을 빼 버린다. 말투만 바꾸고 코딩은 그대로 시키려면 true. (글쓰기·분석 도우미로 쓸 거면 빼도 됨)
  • 그 아래는 자유 서술 — 말투, 언어, 집중할 것, 하지 말 것 등.
4

클로드가 찾는 폴더에 넣는다

둘 중 하나만 고르면 된다. 잘 모르겠으면 사용자 수준을 추천 — 모든 프로젝트에서 쓸 수 있다.

일반 터미널 · 사용자 수준 (모든 프로젝트)
$ mkdir -p ~/.claude/output-styles
$ cp my-style.md ~/.claude/output-styles/
일반 터미널 · 프로젝트 수준 (이 프로젝트만)
$ mkdir -p .claude/output-styles
$ cp my-style.md .claude/output-styles/

파일이 저 폴더 안에 있으면 준비 끝. 클로드가 자동으로 찾는다.

5

적용하고 확인한다

/config → Output style를 다시 열면 내 스타일이 목록에 보인다. 골라서 켠다.

클로드 코드 안에서
/config   # → Output style → "한국어 설명형" 선택

/clear 하거나 새 세션을 열면 그때부터 내가 적은 지침대로 응답한다.

팀 전체의 기본값으로 고정 (선택)

settings.json

/config로 고른 값은 나만 쓰는 .claude/settings.local.json에 저장된다(보통 git에서 제외). 팀원 모두가 같은 스타일로 시작하게 하려면 대신 공유되는 .claude/settings.json의 outputStyle에 이름을 박아 두고 git에 커밋한다.

파일 내용 · .claude/settings.json
{
  "outputStyle": "한국어 설명형"
}

이 파일을 커밋해 공유하면, 팀원이 이 프로젝트를 열 때 자동으로 같은 스타일이 기본이 된다.

안 될 때 여기부터 확인

troubleshooting
▹ 이렇게 확인한다
  • 바꿨는데 안 바뀐 느낌? — 출력 스타일은 세션 시작 때 한 번만 읽는다. /clear 하거나 클로드 코드를 새로 켜면 적용된다.
  • /output-style 이 "없는 명령"이라고 나온다면 — 정상이다. 그 명령은 제거됐고 이제 /config → Output style로 한다.
  • 폴더가 정확한가 — ~/.claude/output-styles/ 또는 프로젝트의 .claude/output-styles/. 오타(output-style 처럼 s 빠짐) 주의.
  • 확장자가 .md 인가 — my-style.md.txt 처럼 숨은 확장자가 붙지 않았는지 확인.

참고 — 이 폴더의 output-styles/ 안에 실제 예시 3개(korean-architecture-focused · team-standard · team-verified-style)가 들어 있다. 하나 열어 보고 내 것에 맞게 고쳐 쓰는 게 가장 빠르다.
